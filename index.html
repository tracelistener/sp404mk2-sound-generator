p = cycle position 0–1  ·  θ = 2πp  ·  d = Duty 0–1  ·  r = random number drawn once per cycle

On the SP

  • Four voices. With the fork's Sound Generator option the SP plays up to four notes at once, all on the same controls. This page plays one.
  • Duty moves in whole steps. On the SP, Duty is a number from 0 to 100 and each step takes effect immediately, so turning the knob adds some crunch. That's on purpose. This page glides between values.
  • Tone only moves by hand. Nothing modulates Duty, so sweeps are performed. Catch one live with skip-back (MARK), or export a still tone with REC and shape it with the SP's own envelope and effects.
  • Pitch comes for free. Every type reads the same cycle position the stock types use. LPSaw, LPSqr and Organ also read the note to skip harmonics above Nyquist, and Vowel reads it to keep formants fixed in Hz. The others alias on high notes, like the stock Saw.
  • Loudness. This page matches loudness so you compare tone, not level. The SP does it with a fixed table that sets every type and Duty step to roughly the level of the stock Sine.
  • CPU. The first build froze the SP because LPSaw and LPSqr were too heavy for four voices. The current build reads the heavy math from tables made for each Duty step.
  • Grit needs no new memory. It reads the random number the stock code already draws at the start of every cycle.

Built from a trace of firmware 5.52. The new types hook in where stock types above 14 fall silent. Firmware patches and source are in the DOOM OS fork. This page runs in your browser and never talks to the SP. Not affiliated with Roland.
